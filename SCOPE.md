# Scope & Contribution Bar

`ATBGamePort` is an industrial-grade agent skill repository for reverse-engineering and porting classic desktop games into zero-dependency HTML5 Canvas games, powered by [fun.aitobox.com](https://fun.aitobox.com).

## The Bar for Issues & Pull Requests

Every bug report, skill refinement, or pull request is judged against two mandatory criteria:

1. **Observed Porting Failure**: It must describe a concrete failure encountered during a real game porting session:
   - What game architecture/binary was in `source/<game>/` (e.g., PopCap SexyAppFramework PE, MSVC C++, Flash SWF, tracker audio format);
   - Which phase of `atb-game-porting` ran;
   - What the agent produced versus what was required (e.g., a black screen cause, a missed RTTI pattern, an audio CORS failure, or a mobile viewport clipping bug).
   - Purely hypothetical or stylistic rewrites ("it might sound nicer if...") are closed as not planned.
2. **Fits the Progressive Disclosure Architecture**:
   - `SKILL.md` remains a tight phase spine; detailed phase rules belong in the corresponding disclosed sibling file (`REVERSE-ENGINEERING.md`, `ASSETS-AND-I18N.md`, `GAMEPLAY-AND-STORAGE.md`, `CANVAS-AND-UI.md`, `AUDIO-AND-VERIFICATION.md`, or `MIGRATE-TEMPLATE.md`).
   - All checks in `npm run check` must pass with zero errors.

## Out of Scope

- **Committing proprietary game binaries or commercial assets**: This repository distributes the porting skills, templates, and verification scripts—never copyrighted third-party `.exe` binaries or commercial game assets.
- **Heavy frontend framework lock-in**: Target ports generated by `atb-game-porting` are zero-dependency native HTML5 Canvas + Web Audio applications that run both over HTTP and via offline `file:///` double-clicking.
