# ATBPort Skills

Industrial-grade agent skills for classic game reverse engineering and zero-dependency HTML5 Canvas porting, powered by [fun.aitobox.com](https://fun.aitobox.com).

## Model-invoked

- **[atb-game-porting](./atb-game-porting/SKILL.md)**: End-to-end static reverse engineering, automated asset & 6-language i18n restructuring, localStorage cross-device save persistence, responsive mobile/desktop adaptation, and zero-black-screen HTML5 Canvas porting of classic desktop games.
- **[atb-game-package](./atb-game-package/SKILL.md)**: Zero-dependency offline packaging toolchain for Web/HTML5 Canvas games, producing self-contained standalone HTML files with embedded VFS and runtime interceptor shims, portable directories with native macOS/Windows double-click launchers, and distribution zip archives.
